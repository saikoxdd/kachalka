# Качалка

Личный трекер тренировок под трёхнедельный цикл: лёгкая (18 повторов), средняя (12) и тяжёлая (6-8) неделя. После каждого цикла рабочие веса растут, если план добит.

Работает как iOS-приложение с Live Activity на Dynamic Island, как Telegram Mini App и как веб-приложение, которое ставится на главный экран из Safari.

## Возможности

- Программа по дням (грудь, спина, ноги) с целями на каждую неделю и автоматической прогрессией весов
- Отметка подходов, замена упражнений на альтернативы, перемещение упражнений вверх и вниз с запоминанием порядка
- Таймер отдыха: стартует после подхода, время настраивается для каждой недели, есть уведомление в фоне
- **Live Activity** на Dynamic Island и экране блокировки: секундомер тренировки, обратный отсчёт отдыха и текущий подход
- Подсказки: блины на сторону для штанги и разминочные подходы
- Итог тренировки: время, подходы, тоннаж, сравнение с прошлой такой же тренировкой, рекорды
- Прогресс: графики рабочих весов по циклам, расчётный максимум на раз, график веса тела
- История с тоннажем и статистикой за неделю, резервная копия в файл

## Структура

```
ios/   Xcode-проект: SwiftUI-оболочка с WKWebView + расширение Live Activity (WidgetKit)
web/   та же страница для Telegram Mini App и установки через Safari (PWA)
```

Весь интерфейс и логика живут в одном `index.html`. Нативная часть отвечает за хранение данных в файле, вибрацию, уведомления, звук, негаснущий экран и Live Activity. Страница общается с ней через `webkit.messageHandlers`.

## Сборка на iPhone

1. Открыть `ios/Kachalka.xcodeproj` в Xcode.
2. В Signing & Capabilities выбрать свою команду (Team) для обоих таргетов: `Kachalka` и `KachalkaLive`.
3. Подключить iPhone, включить режим разработчика, нажать Run.

Требуется iOS 16.2 или новее. На бесплатном аккаунте Apple подпись действует 7 дней, а расширение Live Activity занимает отдельное место из трёх доступных.

## Веб-версия

Содержимое `web/` раздаётся с любого HTTPS-хостинга. В Telegram данные хранятся в CloudStorage бота, в браузере - локально.
